# Статус чеклиста MVP 0.1

Чеклист — из [ROADMAP.md](ROADMAP.md), раздел «Чеклист приёмки MVP 0.1». Состояние на 27 ноября 2026, ветка `feat/0.1-loot-and-mvp` (задачи 11 и 12 одним PR; задачи 1–10 уже на `main`).

Условные обозначения:

- **Сделано** — есть код и автоматический тест (JUnit или GameTest в мире с Create).
- **С оговоркой** — работает, но часть решения временная или упрощённая; оговорка названа.
- **Не проверено в игре** — автоматические тесты есть или нет, но руками на клиенте это не гонялось.

Руками на клиенте не гонялось **ничего**: все проверки — JUnit и `runGameTestServer`. Это относится к каждой строке ниже, «не проверено в игре» отмечено там, где риск заметнее.

## Не проверено в игре

- Клиент целиком: тултипы, иконки, вкладка, экран терминала.
- JEI/EMI (не подключены; скрытие цепочки — задача 1.0).
- Конкретные данжи сборки Ikaria и модовые структуры (YUNG's и др.).
- Баланс всех чисел: шансы лута, веса тиров, шаги, число деплоеров, ресурсы попытки.
- Живой GUI стоимости деплоеров.
- Выделенный сервер с реальным `config/blueprintforge-server.toml`: множитель проверен GameTest-ом на значении по умолчанию и чистой функцией на 0 (см. ниже).
- Многопользовательская игра (несколько терминалов, гонки за один сундук).
