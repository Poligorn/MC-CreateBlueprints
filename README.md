# Create Blueprints

Аддон к Create для модпака MC-Ikaria. Редкие тировые чертежи, скрытая цепочка станков Create и терминал, который оценивает каждый прогон. Внутренний `mod_id` остаётся `blueprintforge`.

**Статус: ранний MVP 0.1, не публичный билд.** Что есть: хуки пресса и массового обжига без рецептов, датапак тиров и целей, предмет чертежа с официальными иконками, блок терминала с GUI. Что заглушка: генератор цепочки, сканер линии, усиленный предмет и хлам. Подробности и канон — в `docs/`.

## Как это задумано

Игрок находит чертёж (тир T1–T5, один тип предмета). В терминале виден только состав цепочки: сколько шагов и сколько операций каждого типа, без порядка. Предмет-цель превращается в заготовку, её нужно провести по линии из станков Create. После прогона терминал пишет процент шагов, стоящих на своих местах. Усиленный предмет выдаётся только при 100%, иначе хлам. Рецепты этих операций не регистрируются и в JEI/EMI не видны.

## Стек

Minecraft 1.21.1, NeoForge 21.1.252, Java 21, Create `6.0.10-281` (диапазон `[6.0.10,)`), Ponder `1.0.87+mc1.21.1`, Flywheel `1.0.7-48`, Registrate `MC1.21-1.3.0+67`. Create 6.0.11 не подключать: публичного релиза для игрока нет.

## Сборка и проверка

Нужна Java 21. Зависимости скачивает Gradle.

| Команда | Что делает |
|---|---|
| `./gradlew test` | JUnit |
| `./gradlew build` | Jar и JUnit |
| `./gradlew runGameTestServer` | Гейм-тесты в мире с Create, ненулевой код при провале теста |
| `./gradlew runClient` | Клиент для ручной проверки |
| `./gradlew runServer` | Выделенный сервер в `run/` (нужен `run/eula.txt` с `eula=true`) |

`runGameTestServer` может завершиться успехом при падении загрузки мода: ищите в логе строку `All N required tests passed`. В dev-запусках в логе есть ошибки тестового датапака `blueprintforge_test`: файлы битые намеренно, в jar игрока их нет.

## Ручная проверка

```
/give @s blueprintforge:terminal
/give @s blueprintforge:research_blueprint[blueprintforge:research_blueprint={tier:"blueprintforge:t2",target:"blueprintforge:iron_pickaxe",item:"minecraft:iron_pickaxe",symbol:"pickaxe",sprite_tier:2}]
/give @s minecraft:iron_pickaxe
```

Чертежи оригиналов также лежат в творческой вкладке «Blueprint Forge». Поставьте терминал, откройте его ПКМ, положите чертёж и кирку shift-кликом, нажмите «Заготовка».

## Датапак

- `data/<ns>/research_tier/<id>.json` — тир: диапазон шагов, операции, множитель бонуса, цвет, `sprite_tier`, стоимость попытки.
- `data/<ns>/research_target/<id>.json` — цель: предмет и тип символа иконки.

Битый файл пропускается с ошибкой в логе, остальное грузится.
