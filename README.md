# Blueprint Forge

Аддон для Create. Чертежи заменяют стол зачарований как источник силы: оригинал — капитал, копия — товар, завод выпускает предметы T2 и выше. Контент модпака живёт в datapack, без пересборки мода.

Стек, на который рассчитан мод: Minecraft 1.21.1, NeoForge, Java 21, Create 6.0.11+.

## Статус

Реализована фаза MVP из дорожной карты (внутренний вертикальный срез, не публичный билд). Следующая фаза — v1.0, первая играбельная сборка.

## Сборка и проверка

Нужна Java 21. Зависимости (NeoForge, Create, Ponder, Flywheel, Registrate) скачиваются Gradle.

| Команда | Что делает |
|---|---|
| `./gradlew build` | Сборка jar и JUnit-тесты |
| `./gradlew runGameTestServer` | Гейм-тесты в мире с Create, завершается кодом ошибки при провале |
| `./gradlew runServer` | Dedicated-сервер в `run/` (нужен `run/eula.txt` с `eula=true`) |
| `./gradlew runClient` | Клиент для ручной проверки |

Гейм-тесты лежат в отдельном source set `src/gametest` и в jar не попадают. Там же тестовый datapack `blueprintforge_test` с намеренно битыми файлами, поэтому в dev-запусках в логе всегда есть три ошибки загрузки — так и задумано.

Серверный конфиг: `config/blueprintforge-server.toml`. Текстуры-заготовки и шаблон гейм-теста пересоздаются `python3 tools/gen_assets.py`.

## Зафиксировано до кода

- Зачарование по умолчанию в режиме `restricted`: T1 можно зачаровать, T2+ нельзя.
- Свой обрабатывающий станок один — Архив. Предметы выпускают станки Create.
- Своей системы приватов нет. Оригинал лежит в блоке и остаётся в мире после выхода игрока.
- Оригинал можно унести и украсть. Добровольная передача дополнительно подтверждается обеими сторонами и пишется в журнал.
- Фитинги, древние роллы, пьедесталы, decay и биржа не входят в первую играбельную фазу.
