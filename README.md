# Create Blueprints

Аддон к Create для модпака MC-Ikaria. Редкие тировые чертежи, скрытая цепочка станков Create и терминал, который оценивает каждый прогон. Вдохновение — чертежи EVE Online, не лор EVE. Внутренний `mod_id` остаётся `blueprintforge`, отображаемое имя — «Blueprint Forge».

**Статус: ранний MVP 0.1 (`0.1.0-mvp`), не публичный билд.** Ничего из перечисленного ниже не проверялось руками на клиенте: проверки — JUnit и GameTests. Подробный статус по пунктам приёмки: [docs/MVP_0.1_STATUS.md](docs/MVP_0.1_STATUS.md).

## Как играть в 0.1

1. Найдите чертёж T1–T3 в сундуке данжа (очень редко — в простых сундуках) или возьмите его на творческой вкладке «Blueprint Forge». Чертёж делает один тип предмета: оружие, броню или инструмент. Цвет иконки — тир, символ — тип.
2. Возьмите терминал с творческой вкладки или командой (рецепта крафта терминала в 0.1 нет), поставьте его и откройте ПКМ. Положите чертёж и предмет-цель (для кирки T2 это железная кирка), нажмите «Заготовка». Терминал показывает только число шагов и операции по типам, без порядка, и то, чего не хватает линии рядом.
3. Заготовка выходит с порта терминала. Проведите её по линии станков Create: пресс и вентилятор за лавой (массовый обжиг), деплоеры с ресурсами тира. Порядок станков вы подбираете сами.
4. Верните заготовку в терминал. Он пишет процент шагов, стоящих на своих местах. **Только 100% даёт усиленный предмет** (золотое имя, блеск зачарования, строка тира), всё меньше — хлам. Предмет-цель и ресурсы деплоеров тратятся в обоих случаях. Процент — только обратная связь.

Рецепты операций мод не регистрирует, в JEI/EMI их нет.

### Что входит в 0.1

Чертежи-оригиналы T1–T3 (меч, кирка, нагрудник и остальные ванильные типы по лесенке материалов), сид и детерминированная цепочка, терминал-прототип, пресс и массовый обжиг без рецептов, деплоеры с ценой по тирам, оценка прогона, хлам, лут в сундуках, творческая вкладка.

### Что не входит

Копии и перегрев (0.2), кастомизация и сторонние предметы (0.3), T4–T5 (0.4; их данные в репозитории есть, но из лута не выдаются), структуры и рынок (0.5), финальный GUI терминала и скрытие из JEI/EMI (1.0). Уникальные эффекты результата отложены на 0.3. Терминал v3 (PR #18) — отдельная работа, не часть этого состояния.

## Стек

Minecraft 1.21.1, NeoForge 21.1.252, Java 21, Create `6.0.10-281` (диапазон `[6.0.10,)`), Ponder `1.0.87+mc1.21.1`, Flywheel `1.0.7-48`, Registrate `MC1.21-1.3.0+67`. Create 6.0.11 не подключать: публичного релиза для игрока нет.

## Сборка и проверка

Нужна Java 21. Зависимости скачивает Gradle.

| Команда | Что делает |
|---|---|
| `./gradlew test` | JUnit |
| `./gradlew build` | Jar и JUnit |
| `./gradlew runGameTestServer` | Гейм-тесты в мире с Create, ненулевой код при провале теста |
| `./gradlew runClient` | Клиент для ручной проверки |
| `./gradlew runServer` | Выделенный сервер в `run/` (нужен `run/eula.txt` с `eula=true`) |

`runGameTestServer` может завершиться успехом при падении загрузки мода: ищите в логе строку `All N required tests passed`. В dev-запусках в логе есть ошибки тестового датапака `blueprintforge_test`: файлы битые намеренно, в jar игрока их нет. Гейм-тесты живут в `src/gametest` и в игровой jar не попадают.

## Ручная проверка

Команд мода нет, используйте ванильные:

```
/give @s blueprintforge:terminal
/give @s blueprintforge:research_blueprint[blueprintforge:research_blueprint={tier:"blueprintforge:t2",target:"blueprintforge:iron_pickaxe",item:"minecraft:iron_pickaxe",symbol:"pickaxe",sprite_tier:2}]
/give @s minecraft:iron_pickaxe
```

Сид выдаётся, когда чертёж попадает в инвентарь (проверка раз в секунду) или в терминал. Для проверки лута: поставьте сундук и привяжите таблицу `/data merge block <x> <y> <z> {LootTable:"minecraft:chests/simple_dungeon"}`, затем откройте; для массовой проверки поставьте `rarity.multiplier = 1000` в конфиге. Вкладка «Blueprint Forge» содержит терминал и все чертежи (оригинал и копия на каждую цель).

## Датапак

Все данные читаются из `data/<ns>/...`; битый файл пропускается с ошибкой в логе, остальное грузится, сервер не падает.

- `research_tier/<id>.json` — тир: диапазон шагов, операции, множитель бонуса, цвет, `sprite_tier`, стоимость попытки (число деплоеров и пул ресурсов).
- `research_target/<id>.json` — цель: предмет, тип символа иконки и тир, к которому она относится. Цель, чей предмет отсутствует в сборке, молча неактивна.
- `blueprint_source/<id>.json` — источник лута (ниже).

### Источники лута

```json
{
  "_comment": "любые лишние поля игнорируются",
  "type": "chest",
  "tables": ["minecraft:chests/simple_dungeon", "minecraft:chests/desert_pyramid"],
  "chance": 0.1,
  "tier_weights": { "blueprintforge:t1": 85, "blueprintforge:t2": 15 }
}
```

- `type` — только `chest`. `mob_drop` и любой неизвестный тип отвергаются с ошибкой в логе: **с мобов чертежи не падают**. Таблицы `entities/...` в `tables` тоже отвергаются, а сам модификатор не добавляет ничего, если в контексте есть источник урона.
- `chance` — 0..1 на каждое открытие таблицы, до множителя.
- `tier_weights` — вес тира; тир берётся по весам, цель выбирается равновероятно среди целей этого тира. Тиры выше T3 не выпадают, даже если перечислены. Тир без целей пропускается.
- Чертёж из лута — оригинал, `generator_version` текущий (1), сид присвоен сразу при генерации.

Глобальный модификатор `blueprintforge:blueprint_sources` (в `data/neoforge/loot_modifiers/global_loot_modifiers.json`) добавляет чертёж к результату броска, ничего не заменяя.

**Черновик, не канон.** Набор таблиц и числа — временная заглушка (`TODO(egor)`), набор для сборки Ikaria не утверждён (открытые вопросы 20 и 21):

| Файл | Таблицы | Шанс | Тиры (веса) |
|---|---|---|---|
| `simple_chests` | деревенские сундуки: оружейник, кузнец-инструментальщик, бронник | 0.01 | T1 |
| `common_dungeons` | simple_dungeon, abandoned_mineshaft, desert_pyramid, jungle_temple, pillager_outpost, shipwreck_treasure | 0.10 | T1 85, T2 15 |
| `rare_structures` | ancient_city, end_city_treasure, bastion_treasure, bastion_other, stronghold_corridor/crossing/library, woodland_mansion | 0.15 | T1 30, T2 50, T3 20 |

Модовые данжи (YUNG's и т. п.) не подключены. Автор сборки может добавить свой файл в `blueprint_source/` или переопределить эти.

## Конфиг

`config/blueprintforge-server.toml` (серверный):

```toml
[rarity]
    # Множитель шанса каждого источника лута; результат chance*multiplier зажимается в 0..1. 0 выключает лут чертежей.
    multiplier = 1.0   # диапазон 0.0 .. 1000.0
```

Если конфиг ещё не загружен, используется 1.0.

## Что не проверялось на клиенте и в игре

- Клиентская часть целиком: иконки, тултипы, вкладка, экран терминала, поведение на выделенном сервере с игроками.
- JEI/EMI: не подключены, скрытие цепочки — 1.0.
- Реальные данжи сборки Ikaria и модовые структуры; набор таблиц и все шансы — заглушка.
- Баланс чисел: шаги тиров, число деплоеров, ресурсы попытки, шансы и веса лута.
- Живой GUI стоимости деплоеров.
- Множитель лута на реальном `blueprintforge-server.toml`: GameTest проверяет значение по умолчанию, а 0 — через чистую функцию `BlueprintLoot.roll`.
- Временные ответы на открытые вопросы (Q2, Q3, Q5, Q6, Q20, Q21, Q40–Q42) помечены в коде `TODO(egor)` и перечислены в [docs/MVP_0.1_STATUS.md](docs/MVP_0.1_STATUS.md).
